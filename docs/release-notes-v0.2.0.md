# 鲸语 TTS v0.2.0（预览版，尚未发布）

## 新增

- 设置页新增「关于与更新」，支持自动和手动检查版本。优先解析 GitHub releases/latest 跳转，API 作为兜底；缓存 6 小时，收到 403/429 后冷却 30 分钟。
- 新增用量与费用统计，包括今日、近 7 天、近 30 天和累计数据，以及最近约 6 个月的热力图。成功合成后记录日期、字符数和请求数。
- 费用页面按 DeepSeek 限时价 ¥1.5 / 万字符估算，并注明以账单为准。

## 改进

- 长文朗读使用 DeepSeek 官方的 10,000 计费字符上限；`TextToSpeech.speak()` 每次最多 4,000 字符，因此超长文本会在本地按句切分后排队朗读。
- 语速与音调移至首页试听卡片，紧邻试听文字与播放按钮；设置页只保留朗读选项，设置项即时保存。
- 用量热力图默认滚动到当前周，不再绘制尚未到来的日期。
- 应用不限制朗读次数或每日用量，费用按 DeepSeek 账户实际用量结算。
- 更新检查只提示版本，不在应用内下载或安装。

## 修复

- 第三方应用调用时不再忽略应用内设置的语速与音调：调用方未指定时以应用设置为基准，指定时按倍数叠加；应用内试听不会重复缩放。
- 为 Android 8/9 添加调用方 UID API 版本保护，避免调用 Android 10（API 29）才提供的方法时发生崩溃。
- 第三方引擎默认开启；升级时迁移旧版访问策略，避免沿用旧的默认关闭状态。
- 修复深色模式状态栏区域底色异常、首页进入设置时保留滚动位置，以及关于页版本号显示问题。

## 其他

- 许可证变更为 MIT。

## 已知问题

- 仅支持 DeepSeek 官方接口 wss://api.deepseek.com/v1/tools/tts；会校验连接地址并拒绝中转、镜像及第三方兼容端点。本地回环仅供自动化测试。
- 尚未在真机、Android 8 实机、OEM 系统设置、TalkBack、大字体或横屏环境验证。
